## NOT verified — deliberately left out

- **Rates / prices:** no publicly verifiable rates for this hotel exist (no OTA price listing found). The page therefore shows "Rates on enquiry" everywhere and the form confirms rates by WhatsApp. No number was invented.
- **Exact room count:** sources conflict (Wild Frontiers says 11 rooms; tripsnomad says 15). No count is stated on the page.
- **Other room types:** only the "Deluxe Room" name is published (Traverse). No other room names were invented; the form offers "Deluxe Room / Any available room / No preference".
- **Free Wi-Fi:** claimed for other Ghizer hotels in search results but NOT verified for Fort Hotel Yasin specifically — left out.
- **Hotel's own Facebook/Instagram links:** no official page could be confirmed, so no social links are shown (footer has WhatsApp + phone only).
- **Street address:** only "Yasin Valley, Ghizer District, Gilgit-Baltistan" is public; no street address was invented.
